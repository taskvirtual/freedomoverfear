# Freedom Over Fear — Landing Page Sample

A static preview of the Freedom Over Fear landing page and its thank-you page, made for client review. It isn't the live Squarespace site.

- `index.html` is the landing page.
- `thank-you.html` is the page visitors see after they sign up.
- `assets/` holds the images, taken from the Truth Guide.

## Publish with GitHub Pages

1. Create a new public repository on GitHub, for example `freedom-over-fear-preview`.
2. Upload every file and folder in this package to the repository root. You can use **Add file → Upload files**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*. Set **Branch** to `main` and the folder to `/ (root)`, then click **Save**.
5. After about a minute, the site is live at `https://<your-username>.github.io/freedom-over-fear-preview/`.

The form and buttons are for preview only. Clicking "Get My Free Guide" opens the thank-you page, and nothing is submitted.
